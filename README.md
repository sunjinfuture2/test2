# AI 데이터센터 내부 둘러보기 (First-person walkthrough)

충주 AI 데이터센터 도면을 실측 미터 스케일로 세우고, 1인칭으로 걸어
다니며 장비를 살펴보는 웹 시뮬레이션입니다. 부감 다이어그램인
[test 저장소의 3D 용어사전](https://github.com/sunjinfuture2/test)과 같은
도면·같은 용어 데이터를 쓰되, 실내에서 보이도록 재질·조명·충돌을 새로
구성했습니다.

**바로 보기 →** https://sunjinfuture2.github.io/test2/walk/

## 조작

| 키 | 동작 |
| --- | --- |
| `W` `A` `S` `D` / 화살표 | 이동 |
| 마우스 | 시선 |
| `Shift` | 달리기 (2.1배) |
| `Space` | 조준한 장비 설명 열기/닫기 |
| `PgUp` `PgDn` | 층 이동 (B1 · 1F · 2F · 옥상) |
| `1` `2` `3` `4` | 걷는 속도 (0.9 / 1.4 / 2.2 / 3.4 m/s) |
| `Esc` | 마우스 잠금 해제 |

## 구조

```
app/                Vite + React + three.js 소스
  src/scene/        도면 지오메트리 (test 저장소와 공유하는 빌더)
  src/walk/         1인칭 전용 — 월드 개조·조명·충돌·컨트롤러·HUD
  src/data/terms.js 장비 설명 데이터
walk/               빌드 산출물 (GitHub Pages가 서빙)
```

### 부감 씬을 실내로 바꾸는 부분

원본은 위에서 내려다보라고 만든 모델이라 그대로 들어가면 종이 모형
속처럼 보입니다. `src/walk/buildWorld.js`가 아래를 바꿉니다.

- 반투명 구조체 → 불투명, Lambert → Standard (거칠기·금속성)
- 계통 구분용 색(전력=노랑 등)의 채도를 죽여 실제 회색 설비로. 색을
  살리는 것은 0.6 m 미만의 작은 면(표시등·표지)뿐입니다.
- 천장 라인 조명 + 안개 + ACES 톤매핑 — 데이터센터 특유의 균일한
  밝기와 복도 깊이감
- 다이어그램용 윤곽선·고스트 쉘·층 구분 바닥판은 전부 끕니다

### 충돌과 조준

- 충돌: 2 m 공간 해시 위의 수평 AABB. 축을 나눠 밀어서 벽에 닿으면
  멈추지 않고 미끄러집니다. 장비는 그룹이 아니라 **메시 단위**로 잡습니다
  — 그룹으로 잡으면 랙 9열이 통째로 한 덩어리가 되어 홀이 막힙니다.
- 조준: 화면 중앙에서 레이 5발(중앙 + 상하좌우 약 4°)을 쏴 처음 맞은
  메시의 용어를 집습니다. 벽·바닥이 먼저 맞으면 조준 없음 — 벽 너머
  장비는 잡히지 않습니다.

